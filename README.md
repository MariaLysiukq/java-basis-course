# OPU Java Basics

[![Java Version](https://img.shields.io/badge/Java-17%2B-orange.svg)](https://www.oracle.com/java/)

A learning repository containing solutions for the **Java Basics** course at OPU. This project tracks my progress through practical exercises covering fundamental Java concepts, syntax, and object-oriented programming basics.

## Project Overview

This repository is structured as a step-by-step module-based course. Each module focuses on a specific set of Java topics with practical programming tasks.

## Course Modules & Progress

- [x] **1. First Java App** — Introduction to Java, main method, and standard output.
- [x] **2. Variables & Data Types** — Primitive types, variable declaration, and basic operations.
- [x] **3. Expressions** — Arithmetic operations, precedence, and string concatenation.
- [x] **4. Logic & Branching** — Conditional statements (`if-else`, `switch`), boolean logic.
- [x] **5. Loops** — Iteration using `for`, `while`, and `do-while`.
- [x] **6. Methods** — Method definition, parameters, return types, and overloading.
- [x] **7. Final Practice** — Consolidating core concepts through comprehensive tasks.
- [x] **8. Upcoming Topics** — core concepts of Object-Oriented Programming (OOP) in Java: Classes, Objects, State, Behavior, and Constructors. It consists of two parts: Payer, WaterTank

## How to Run

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Marialysiukq/opu-java-basics.git](https://github.com/Marialysiukq/opu-java-basics.git)
    ```
    Open IntelliJ IDEA:
   
        Select File → Open and navigate to the cloned project folder.

    Execute Tasks:
   
        Navigate to any lesson subfolder
        Run the file directly inside the IDE using Shift + F10 or clicking the green Run arrow.
